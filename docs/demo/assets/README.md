# Demo deck icon assets

The SVG service icons in this folder come from the official Microsoft Azure Architecture Center icon package:

- https://learn.microsoft.com/azure/architecture/icons/
- https://arch-center.azureedge.net/icons/Azure_Public_Service_Icons_V24.zip

The Azure product logo comes from the official Microsoft Azure brand asset:

- https://azure.microsoft.com/content/dam/microsoft/final/en-us/microsoft-brand/icons/Azure.svg

The PNG files are transparent native-PowerPoint renders of those SVG assets for reliable embedding by `scripts/generate_ai_feasibility_demo_deck.py`. The source icons are not cropped, rotated, recolored, or distorted, and product names are shown adjacent to the icons in the deck.
