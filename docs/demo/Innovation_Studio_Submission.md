# Innovation Studio submission

## Project title

Azure Migrate AI Feasibility Assessment

## Tagline

Turn application intelligence into evidence-backed AI modernization decisions.

## Description

Azure Migrate already helps customers understand where and how an application should run in Azure. This project extends that journey with a second decision: **where can AI create meaningful value in an existing application, and what would it take to deliver that value responsibly?**

The **AI Feasibility Assessment** is a working simulator prototype that combines two evidence streams:

- **Azure Migrate context:** application boundaries, dependencies, runtimes, assessed Azure targets, readiness, and cost.
- **Customer context:** workflow, users, desired outcome, authorized data, constraints, compliance requirements, and expected usage.

For each application-and-workflow pair, it generates a versioned, reviewable decision pack covering business fit, data readiness, integration readiness, security and governance, delivery and operations, and economics. Observed, customer-provided, inferred, and missing evidence remain separate. Deterministic rules and cost calculations drive the recommendation; Microsoft Foundry GPT-6.1 improves only the grounded executive narrative.

The demo follows BPTco's document-processing workflow. The customer selects the discovered application, describes classification, extraction, and enrichment goals, confirms the model-processing boundary, and receives proposed Azure capabilities, low/base/high indicative cost scenarios, explicit gaps, a bounded proof-of-concept plan, and production gates. One action then creates a linked AI-ready architecture that preserves the original migration design, marks every AI component as proposed, and separates base migration cost from incremental AI planning cost.

The assessment can recommend a proof of concept, remediation first, conventional automation, an existing product, or no AI. It is not an opaque score, a production-readiness certificate, or an autonomous deployment tool.

**Why it matters:** migration context no longer has to be reconstructed in a separate AI workshop. Application owners get an inspectable investment decision; architects and delivery teams get a qualified handoff; Microsoft and partners get a practical bridge from migration planning to responsible AI adoption.

Built for Hackathon 2026 as a bounded concept to validate with design partners. The next step is human-reviewed evaluation across real application/workflow pairs, measuring decision usefulness, effort reduction, safety, and accepted PoC handoffs.
